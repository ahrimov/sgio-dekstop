**Запуск приложения**
выполняем последовательно:
`npm install` -> установка зависимостей
`npm run prod` -> запуск приложения

Тестирование:
`npm run test` -> прогнать тесты

.env файл используется для установки параметров запуска приложения.
отсутствие какого либо из его параметров приведет к неработоспособности приложения.
BASE_URL и PORT используются для запроска данных из БД при обращении на роут /run_ute_task
